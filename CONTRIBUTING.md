# Contributing

Keep the fixed Bash coordinator small and place numerical contracts in testable Python/R helpers. Preserve imported matrix immutability and biological identity. No sample rebalancing, duplicate biological observations, implicit pool creation, or same-data formal loop inference is acceptable.

Use Python 3.11+, explicit scientific prefixes and direct argument arrays. CSV/TSV is parsed with the shared parser; never source metadata rows. Set strict Bash flags and collect every background child. Add meaningful numerical tests for new scientific behavior, masks, NA/zero semantics and failure paths. Do not write tests that only mirror source code or file existence.

Run appropriate pytest, Bash syntax, full descriptive Linux fixture and optional R checks. Document skipped checks and environment failures. Every scientific change invalidates relevant completion/calibration keys; preserve source/environment/input evidence. Freeze calibration policies before evaluating them, and review biological truth for relative quantities.

Update schemas, variable documentation, stage output/method descriptions and release evidence when interfaces change. Keep private fixtures/manifests and generated maps outside the public archive. Discuss deferred models or workflow-engine migration separately. Project licensing/ownership remains pending; do not import upstream source under an assumed license.
