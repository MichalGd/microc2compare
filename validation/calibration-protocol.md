# Prespecified v0.1 calibration protocol

Software tests and contact thinning do not establish biological false-positive control. Before production inference, run this protocol with the exact R/core environments, source digest, count filter, exposure recipe and supported design. Register real biological negative controls separately; simulations cannot replace them.

Primary simulation scenarios are equal-depth null, unequal-depth null, a mixture with 10% changes, broad effects with 30% changes, and sparse-count null. The separate `--design paired` suite adds paired null and uses three matched subjects. Run at least 200 independent datasets per scenario and module with base seed 20261007. Loops use an independent frozen candidate grid with nonnegative NB counts and fixed global eligible-cis totals: background contacts fill the remainder. This defines unchanged candidate allocation even under broad effects; changing the denominator and calling the other candidates null would misstate the estimand. Insulation uses a fixed complete grid and continuous spatially correlated noise, with matched subject effects in the paired suite. Filtering, design checks, exposure construction and the actual shipped R adapters run together. Formal candidate selection from analysis samples remains unsupported regardless of calibration.

At nominal BH FDR 0.05, require the upper 95% Monte Carlo bound for the mean false discovery proportion to be at most 0.075 for every primary scenario. Report power and bias separately. Null truth is defined for relative contact allocation/relative insulation, not absolute contacts. Changed-distance-decay cases require an explicitly declared non-null truth rather than being mislabeled null. Bounds use a fixed seeded bootstrap and normal approximation over independent datasets, taking the larger upper endpoint. If every observed FDP is zero, use the conservative Clopper-Pearson upper bound for any false-discovery event rather than reporting a zero uncertainty bound. These finite-simulation bounds themselves need review and cannot certify all real-data distributions.

Failure blocks inference. Freeze settings before execution; record any protocol revision and its reason. A passing artifact identifies source, environment, module, additive design and parameter recipe, and points to hashed scenario results. Test paired designs separately with at least three pairs and two residual degrees of freedom. Small label permutations must respect subject blocks and cannot support precise tail calibration.

Run `scripts/calibrate.py --help` for explicit execution. The default independent unpaired suite does not certify arbitrary covariate designs, real-data behavior, or compartment/domain inference. Additional supported design keys need their own simulation and biological controls. No passing statistical calibration artifact is supplied with the initial implementation.

`--units-per-condition` defaults to three; use two for a separately calibrated unpaired preliminary design, or the actual larger group size. Three-replicate evidence does not transfer to two replicates. The key includes group sizes, subject/observation counts and residual df. Numeric-looking subject/batch labels remain factors. Two matched pairs fail the df policy. The primary suite fixes nominal FDR 0.05 and rejects other thresholds until its protocol is explicitly revised and reviewed.
